# VisionLink

VisionLink is a robotics project for assistive navigation and interaction.

## Structure
- `src/`: main Python source code
- `assets/images/`: test or demo images
- `assets/audio/`: audio assets
- `docs/`: project documents

## Features
- Camera-based perception
- Motor control
- Speaker / voice interaction

## Environment
- Raspberry Pi
- Python
- ROS / micro-ROS related development environment

## Notes
This repository is organized for portfolio presentation, focusing on core source files and assets.
